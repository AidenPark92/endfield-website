## 1. 전투의 기본 구조

| 항목 | 내용 |
|---|---|
| 편성 | 4인 파티. 조작 캐릭터 1명 + 비조작 3명(자동 일반 공격, 받는 피해 감소). Q / F1~F4로 교대 ✅ |
| 직업 6종 | 뱅가드(자원 수급) · 가드(디버퍼/서브딜) · 캐스터(아츠 서브딜) · 스트라이커(메인 딜) · 서포터(힐·버프) · 디펜더(탱커) |
| 속성 | 물리 / 열기 / 냉기 / 전기 / 자연 (아츠 4속성 + 물리) |
| 능력치 | 힘(HP +5/pt) · 민첩(물리 저항) · 지능(아츠 저항) · 의지(받는 치유 +0.1%/pt). 주 능력치 1pt = 공격력 +0.5%, 보조 능력치 1pt = +0.2% ✅ |

### 행동 4종
1. **일반 공격** — 마지막 타 = **강력한 일격(Final Strike)**: 고배율 + 불균형치 + **SP 회복**. 비조작 캐릭터의 막타는 SP·불균형 없음 ✅ (🎮 "메인 컨트롤 오퍼레이터라면 강력한 일격이 N포인트의 불균형 피해")
2. **배틀 스킬** — **SP 100(1칸) 소모, 쿨타임 없음** ✅. 사용 시 팀 궁극기 에너지 획득.
3. **연계 스킬(Combo Skill)** — SP 소모 없음, **캐릭터별 발동 조건 + 쿨타임**. 조건 충족 후 **약 7초 안에 E** 입력 ✅
4. **궁극기** — 에너지 가득 차면 배틀 스킬 버튼 길게 누르기(PC Alt+스킬) ✅

### 회피
- 최대 2연속. **극한(저스트) 회피**: 적 공격(빨간 섬광) 타이밍 → 슬로우, 무적, **SP 회복** ✅

## 2. 자원 루프 — SP와 궁극기 에너지

### SP(스킬 게이지) — 팀 공유
- **최대 3칸(300)**, 자연 회복 **1칸 / 약 12.5초(≈8 SP/s)** ✅
- 회복 수단: 강력한 일격, 극한 회피, 처형(🎮 "일정량의 스킬 게이지를 회복", 양은 ⚠️ 25~100설), 뱅가드 고유 효과
- **반환**: 스킬이 SP를 돌려주는 효과. *SP 회복으로 취급되지 않으며, 반환된 SP는 궁극기 에너지를 만들지 않음* ✅

### 궁극기 에너지
- 배틀 스킬: `(반환 미적용 소모 SP / 100) × 6.5` → **팀 전원**에게 ✅
- 연계 스킬: **사용한 본인에게 10** (아크라이트만 5) ✅
- ⇒ 궁극기 회전율 = 배틀 스킬 횟수(팀) + 본인 연계 횟수. 궁극기 필요 에너지는 캐릭터마다 다름(TODO: 캐릭터별 수치 수집)

> **콘텐츠 포인트**: "SP 경제" — 자연 회복만으로는 12.5초에 스킬 1번. 막타·극한 회피·처형·뱅가드로 SP를 얼마나 더 버는지가 DPS를 결정.

## 3. 연계 스킬 — 엔드필드 전투의 핵심

- **발동 조건이 캐릭터마다 다름**. 조건이 충족되면 해당 오퍼레이터 연계 버튼 활성(체력바 위 흰 빛) → 7초 내 입력 ✅
- **동시에 여러 명 충족 시 편성 1번 > 2번 > 3번 > 4번 우선** ✅ → *편성 순서가 곧 연계 순서*
- 제한시간 안에 안 쓰면 쿨타임이 돌지 않음(기회만 날아감) ✅
- 조건 예시 ✅
  - 펠리카: 조작 캐릭터가 **일반 공격 막타** 적중 시 → 강제 감전 부여
  - 질베르타: 적에게 **아츠 이상(반응)** 발생 시
  - 판(Da Pan): 적의 **방어 불능 4스택** 도달 시
  - 스노우샤인: 조작 캐릭터가 피격되고 **HP 60% 미만**
  - 관리자: **다른 오퍼레이터가 연계 스킬로 피해**를 줄 때 → 오리지늄 결정 부착(속박)
  - 탕탕: 적이 **아츠 폭발** 피해를 받으면 (🎮)
  - 레바테인: 적이 **연소 또는 부식** 상태가 되면 (🎮)
  - 아델리아: 조작 캐릭터가 **방어 불능·아츠 부착이 없는** 적에게 강력한 일격 후 (🎮) → 강제 부식
  - 장방이: 강력한 일격/처형으로 **전기 부착** 적 명중 후 → 전기 부착 소모, 강제 감전(이미 감전이면 이상 레벨 +1) (🎮)
- **연쇄 구조**: A의 스킬이 부착/이상을 만들고 → 그게 B의 연계 조건 → B의 연계가 C의 조건… 이 체인을 설계하는 게 파티 구성의 본질
- 스트라이커는 연계 조건이 까다로워(특정 스택·이상 요구) 편성 자유도가 낮음

> **콘텐츠 포인트**: "트리거 그래프" — 각 캐릭터의 *무엇을 만들고(출력) / 무엇에 반응하는지(입력)*를 노드-화살표로 그리면 파티 시너지가 한눈에 보임.

## 4. 불균형(스태거) · 처형

- 적 체력바 아래 흰 게이지. 강력한 일격, 배틀·연계·궁극기, 차지 공격 끊기, 띄우기/넘어뜨리기(+10)로 누적 ✅
- 가득 차면 **불균형 상태**: 행동 불가 + **받는 피해 ×1.3** ✅ (🎮 "받는 피해가 증가", 30%는 📘)
  - 🎮 짧은 시간 안에 다시 불균형에 빠지면, 끝난 뒤 일정 시간 **쌓이는 불균형치 감소**(연속 스태거 억제)
- **처형 공격**: 불균형 적에게 **처음 하는 일반 공격**이 처형 → 무적(🎮 "어떤 피해도 받지 않음"), 대량 피해, SP 회복 ✅
  - 처형 배율: 일반 ×1 / 상급 ×1.25 / 정예 ×1.5 / 보스 ×1.75 ⚠️ **wiki.gg 데미지 공식 문서 단독, 게임 원문·독립 검증 없음** → 실측 필요
  - 🎮 일부 고난도 모드에 "적에게 주는 처형 피해 대폭 증가" 수식어 존재 → 처형 피해는 별도 배율 구간이 있는 것은 확실
- 보스는 게이지가 **스태거 노드**로 나뉨 — 노드 도달 시 짧게 경직 ✅
- 불균형치 규모: 정예 100~120, 스토리 보스 ~300 ⚠️
- **차지 공격(붉은 원)**: 준비 중에 배틀/연계/궁극기 적중 → 중단 + 대량 불균형치. 실패 시 강공격 ✅

## 5. 아츠(원소) 시스템

### 아츠 부착
- 열기·냉기·전기·자연. **같은 속성 최대 4스택**, 단독 효과 없음, 약 20초 갱신 없으면 소멸 ✅

### 아츠 폭발 (같은 속성 추가 부착)
- **160% 해당 속성 피해** + 스택 +1, **부착 소모 안 함** ✅ (🎮 "아츠 폭발이 발동되며 전기 부착 1스택이 추가로 쌓였습니다")

### 아츠 이상(반응) — 다른 속성 부착
- **나중에 들어온 속성이 반응 종류를 결정**, 기존 아츠 부착 **전부 소모** ✅
- **이상 레벨** = 소모된 아츠 부착(또는 방어 불능) 스택 수, 최대 4. 높을수록 효과가 강해짐 ✅ (🎮 원문 정의)
- **강제 부여**(펠리카·아크라이트·장방이 감전, 이본·스노우샤인 동결, 아델리아 부식, 울프가드 연소 등): 🎮 **"강제로 부여된 ○○은 초기 피해가 없습니다"** (연소·감전·동결·부식 모두 동일 문구). 레벨은 별도 명시 없으면 1 📘

| 반응 | 조건(마지막 속성) | 즉발 피해 | 부가 효과 |
|---|---|---|---|
| **연소** | + 열기 | 80% + 80%×레벨 = 160/240/320/400% ✅ | 10초간 초당 12% + 12%×레벨 열기 DoT. 🎮 **지속 피해는 치명타 없음**. 스냅샷 X 📘 |
| **감전** | + 전기 | 160/240/320/400% ✅ | 받는 **아츠 피해 +12/16/20/24%**, 지속 **12/18/24/30초** 📘. 🎮 원문: 스택이 많을수록 "초기 피해 증가 · 지속 시간 증가 · 아츠 피해 증가 효과 강화" → **"12초 고정"설은 기각** |
| **동결** | + 냉기 | **160/240/320/400%** 📘. 🎮 원문: 스택이 많을수록 "초기 피해 증가 · 지속 시간 증가 · 쇄빙 피해 증가" → **"130% 고정"설은 기각** (CBT/구버전 정보로 추정) | 이동 불가 **5.75/6.75/7.75/8.75초**(wiki.gg) ⚠️ 6/7/8/9초 표기 출처도 있음 → 소수점 차이만 실측 |
| **부식** | + 자연 | 160/240/320/400% 📘 | 15초간 **모든 저항 감소**: 즉시 3.6/4.8/6/7.2 → 초당 +0.84/1.12/1.4/1.68 → 최대 12/16/20/24 📘. 🎮 원문: 스택이 많을수록 "초기 피해 · 초당 저항 감소량 · 최대치 증가", **부식이 갱신되면 이미 깎인 저항 유지** ✅ |
| **쇄빙** | 동결 중인 적에게 방어 불능/물리 이상 | **120% + 120%×레벨 물리 피해** = 240~600% ✅ | 동결 소모. 🎮 "대량의 물리 피해" |

- 부식 수치 내부 일관성: 즉시 감소 = 최대치의 30%, 초당 증가 = 최대치의 7% (모든 레벨 동일 비율) → 데이터 테이블 값일 가능성 높음
- 아군이 부착 4스택 받으면: 열기 → 방어 무시 지속 열기 피해(🎮) / 전기 → 기절 + 받는 아츠 피해 증가(🎮) / 냉기 → 이동 불가. 수치 ⚠️

## 6. 물리 이상 시스템

- 물리 오퍼레이터는 아츠 부착 대신 **방어 불능(Vulnerable)** 스택을 쌓음 (최대 4, 20초) ✅
- **방어 불능이 없는 적에게 물리 이상을 걸면 → 방어 불능 1스택만 부여** ✅

| 물리 이상 | 방어 불능 보유 시 효과 |
|---|---|
| **띄우기** (Lift) | 스택 +1, **120% 물리 피해 + 불균형 10**, 약한 적 공중 부양 ✅ |
| **넘어뜨리기** (Knock Down) | 스택 +1, **120% 물리 피해 + 불균형 10**(🎮 "대량의 불균형치"), 약한 적 다운 ✅ |
| **강타** (Crush) | 스택 **전부 소모** → **150% + 150%×스택** (최대 750%) ✅ 🎮 "소모한 방어 불능 스택이 많을수록 피해 증가" |
| **갑옷 파괴** (Breach) | 스택 전부 소모 → **50% + 50%×스택** 피해 + **받는 물리 피해 +12/16/20/24%**, 12/18/24/30초 ✅ 🎮 "스택이 많을수록 효과 증가, 지속 시간 증가" |

> 물리 루프: 띄우기/넘어뜨리기로 4스택 → 강타(폭딜) 또는 갑옷 파괴(물리 딜러용 디버프). 판의 연계(4스택 조건)처럼 스택 수 자체가 트리거가 됨.

## 7. 데미지 공식 (커뮤니티 역산, endfield.wiki.gg / endfieldhub 기준)

```
피해 = 공격력 × 스킬 배율 × 피해 보너스 × 치명타 × 증폭 × 불균형 × 처형 × 연타
       × 허약 × 취약 × 받는 피해 증가 × 피해 감소 × 보호 × 방어 × 저항 × 독립 곱연산
```

| 구간 | 식 | 비고 |
|---|---|---|
| 공격력 | ((캐릭터 기본 + 무기 공격력) × (1 + 공격력%) + 고정 공격력) × 능력치 보너스 | ⚠️ 고정 공격력에 능력치 보너스가 곱해지는지 출처 간 표기 차이 |
| 능력치 보너스 | 1 + 0.005×주 능력치 + 0.002×보조 능력치 | ✅ |
| 스킬 배율 | 스킬 설명의 % | 데이터 수집 필요 |
| 피해 보너스 | 1 + Σ(속성 피해%, 스킬 종류별 피해%, 불균형 적 대상 피해%, 모든 피해%) | **합연산** ✅ |
| 치명타 | 치명 시 1 + 치명 피해(기본 50%), 기본 치명률 5% | 🎮 **지속 피해는 치명 불가** |
| 증폭 (Amp) | 1 + Σ증폭 | 주로 속성별, 합연산 |
| 불균형 | 불균형 상태면 1.3 | ✅ |
| 처형 | 1 / 1.25 / 1.5 / 1.75 (적 등급) | ⚠️ wiki.gg 단독 |
| 연타 (Link) | 다음 **배틀 스킬 +30/45/60/75%**, **궁극기 +20/30/40/50%** (1~4스택) | 특정 오퍼레이터 효과로 부여, 다음 배틀 스킬/궁극기에 소모 |
| 허약 (Weaken) | Π(1 − 허약) | 적이 주는 피해 감소용(아군 방어 계산) |
| 취약 (Susceptibility) | 1 + Σ취약 | 속성별 (🎮 물리 취약 / 아츠 취약 구분 존재) |
| 받는 피해 증가 | 1 + Σ(감전, 갑옷 파괴, 재능 등) | |
| 피해 감소 | Π(1 − 감소) | |
| 보호 | 1 − max(보호) | 가장 큰 것 하나만 |
| 방어 | DEF ≥ 0: 100 / (DEF + 100), DEF < 0: 2 − 0.99^(−DEF) | **적 기본 DEF 100 → 0.5배** ✅ |
| 저항 (적) | (100 − 저항 + 저항 무시 + 부식 감소) / 100 | 1을 넘을 수 있음 |
| 독립 곱연산 | Π(1 + "피해 부스트") | 드문 곱연산 버프 |

### 이상 피해(아츠 폭발·반응·물리 이상)의 별도 계수
- 레벨 계수: 물리 이상 `1 + (레벨 − 1) / 392`, 아츠 폭발·반응·쇄빙 `1 + (레벨 − 1) / 196` 📘 (prydwen도 "레벨에 비례" 언급)
- **아츠 강도**: `1 + 아츠 강도 / 100` (1pt = +1%) 📘. 커뮤니티 실측: 강타(물리 이상)에도 곱연산 적용
- **치명타**: 🎮 *지속 피해(연소 DoT 등)는 치명타 없음*만 공식 확인. **즉발 이상 피해(아츠 폭발·반응 초기·강타·쇄빙)의 치명 여부는 어떤 출처도 명시 안 함** ⚠️
- **피해 보너스·증폭·취약 적용 여부** ⚠️ 출처 없음 → 실측 필요
- 인게임 표시는 소수점 내림, 내부 계산은 소수 그대로

### 계산기 설계 메모
- 구간을 **합연산 그룹(피해 보너스, 증폭, 취약, 받는 피해 증가)** vs **곱연산 그룹**으로 나눠야 "어떤 버프가 효율적인가"를 보여줄 수 있음 (같은 그룹에 몰리면 효율 감소)
- 적 쪽 변수: DEF(기본 100), 속성별 저항, 등급(처형 배율), 불균형 여부
- 시간축 요소: SP 회복, 연타 소모, 감전/갑옷 파괴 지속, 연소 DoT → 단발 피해 계산기 + 로테이션(타임라인) 시뮬레이터 두 단계로
- ⚠️ 항목은 data/*.json에 넣을 때 `"verified": false` + TODO 주석, 📘 항목은 `"source": "wiki.gg"` 표기 (프로젝트 데이터 규칙)
- 이상 피해의 치명/피해 보너스 적용은 **토글 옵션**으로 두고 기본값은 "미적용", 실측 후 확정
