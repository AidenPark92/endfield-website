## 0. 공통 준비
- **녹화**: 60fps 이상(OBS 등). 데미지 숫자·디버프 아이콘을 프레임 단위로 다시 보기 위함. 녹화가 기록 원본.
- **변수 고정**: 같은 적, 버프·연타·불균형 상태 없음(처형 측정 제외), 장비/레벨 변경 금지. 다른 오퍼레이터 자동 공격이 섞이지 않게 **1인 또는 비딜러 편성**.
- **치명타 분리**: 기본 치명률 5% → 같은 측정 **5회 이상**, 최빈값 사용. 치명 값(×(1+치명 피해))은 따로 표시.
- **반올림 오차**: 인게임 표시는 소수점 내림 → 공격력 높은 캐릭터로 숫자를 수천 단위로.
- **스택 수 확인**: 반응 직전 프레임에서 부착/방어 불능 스택 기록.
- 기록 템플릿(CSV): `날짜,항목,오퍼레이터,레벨,아츠강도,적,적등급,스택/레벨,표시피해,치명여부,조건메모,영상타임코드`

## A. 처형 배율
- 피해 = 공격력 × (처형 스킬 배율) × … × **불균형 1.3** × **처형 배율(등급)** × 방어 × 저항
- 처형 스킬 배율 자체를 모르므로 **같은 오퍼레이터의 처형 피해를 적 등급별로 비교**한다.
1. 같은 오퍼레이터·같은 장비로 일반 / 상급 / 정예 / 보스 각각 처형 → `X(등급)`
2. 적마다 방어·저항이 다를 수 있으니, 같은 적에게 **불균형 상태에서 일반 공격 1타(처형 아님)** 도 기록 → `N(등급)` (불균형 1.3은 공통)
3. `처형 배율(등급) ∝ X(등급) / N(등급)` → 일반 적 값을 1로 두고 나눈다
   - 예상: 1 : 1.25 : 1.5 : 1.75
- 주의: 등급 분류(상급/정예/보스)는 적 정보 화면 표기로 기록. 고난도 모드의 "처형 피해 증가" 수식어가 없는 콘텐츠에서 측정.

## B. 즉발 이상 피해의 치명타
- 같은 이상 피해(예: 아츠 폭발 160%)를 **치명률을 높인 상태(치명 장비·버프)** 로 20회 이상 반복
- 값이 두 갈래(기본값, 기본값 × (1+치명 피해))로 나뉘면 → 치명 적용 ✅ / 항상 한 값이면 → 미적용
- 아츠 폭발 · 반응 초기 피해 · 강타 · 쇄빙을 각각 따로 판정 (서로 다를 수 있음)

## C. 즉발 이상 피해의 피해 보너스·증폭·취약
1. 이상 피해 `S0` 측정 (버프 없음)
2. **한 가지 보너스만** 켜고(예: 냉기 피해 +X% 장비, 또는 증폭 버프 Y%) 같은 이상 피해 `S1` 측정
3. `S1 / S0` 이 `1 + X` 이면 적용, `1` 이면 미적용
4. 일반 스킬 피해에도 같은 버프의 효과를 재서 대조 (버프가 실제로 켜졌는지 확인용)
- 피해 보너스 종류별로 반복: 속성 피해%, 스킬 종류별 피해%(배틀 스킬 피해 등 → 이상 피해에는 미적용 예상), 모든 피해%, 증폭, 취약

## D. 동결 지속시간
- 녹화에서 **동결 아이콘이 나타난 프레임 ~ 사라진 프레임**(프레임 수 ÷ fps). 레벨 1~4 각 3회.
- 5.75 / 6.75 / 7.75 / 8.75 인지, 6 / 7 / 8 / 9 인지 판정 (0.25초 = 60fps 기준 15프레임 차이 → 충분히 구분 가능)

## E. (재확인) 반응 수치
### 동결·감전·부식 즉발 피해 = 160/240/320/400%?
- 같은 속성 오퍼레이터의 **아츠 폭발(160%)** 을 기준 자로: 다른 속성 n스택 → 같은 오퍼레이터가 마지막 부착 → 반응 피해 `F(n)`
- `F(n) / 아츠 폭발 피해` ≈ **1.0 / 1.5 / 2.0 / 2.5** 이면 위키 값 확정

### 감전 지속시간·증가량
- 아이콘 표시 시간 → 12/18/24/30초?
- 부착 없는 같은 아츠 타격으로 감전 전 `D0`, 감전 중 `Dn` → `Dn/D0 − 1` = 0.12/0.16/0.20/0.24?
- 물리 피해로 대조 (오르지 않아야 함)

### 부식 저항 감소 곡선
- 피해 ∝ (100 − 저항 + 부식 감소) / 100
- 부식 전 `D0`, 부식 후 1초 간격 15초간 `D(t)` → 저항 0인 적이면 `c(t) = (D(t)/D0 − 1) × 100`
- 레벨 1 기대 곡선: 3.6 → +0.84/초 → 10초쯤 12에서 평평. 레벨 4: 7.2 → +1.68/초 → 24
- 갱신 시 깎인 저항 유지되는지, 물리 피해에도 적용되는지 대조
